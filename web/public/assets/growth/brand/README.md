# Исходные материалы X5 для локального концепта

Получены 05.09.2026 с публичного сайта https://www.x5.ru/en/.

- `x5-logo.svg` — исходный знак, без изменения геометрии и цветов: https://www.x5.ru/wp-content/uploads/2026/05/logo-x5-main-top.svg
- `x5-sans-variable.woff2` — X5 Sans Variable, диапазон веса 300–700: https://www.x5.ru/wp-content/themes/x5/assets/dist/fonts/X5-Sans-VF.81e33e20a976b7fc43a4.woff2
- Источник подключения шрифта: https://www.x5.ru/wp-content/themes/x5/assets/dist/style.min.css

Шрифт подключён локально под CSS-именем `X5 Brand` через общий `web/src/x5-brand.css` для `/landing` и клиентского демо `/`. Это не X5 Sans UI. Проверка соответствующей TTF-версии подтвердила кириллические символы и ось веса 300–700. Нет внешних запросов к сайту X5 для шрифта и логотипа. Promo Studio не переведён на новую тему.
