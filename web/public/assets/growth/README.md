# X5 Рост — full UI asset pack v2

Полный визуальный asset-пак для клиентского приложения и Promo Studio. Файлы не
подключены к текущему React-коду и не меняют существующую функциональность.

Это проектная хакатонная концепция, а не официальный брендбук или официальный
суббренд X5. Логотипы и псевдобрендовые знаки в ассеты не включены.

## Структура

### `hero/`

- `progress-leaf-clay-v2.png` — главный экран прогресса в handcrafted
  claymation; safe-zone сверху 28%.
- `level-up-orange-clay-v2.png` — повышение уровня в handcrafted claymation;
  safe-zone сверху 22%.
- Файлы `*-v1.png` сохранены как предыдущая гладкая 3D-версия и больше не
  являются основными для лендинга.

### `illustrations/`

- `client-challenge-clay-v2.png` — недельный челлендж и корзина в claymation.
- `client-referral-clay-v2.png` — приглашение друга в claymation.
- `client-empty-v1.png` — спокойное пустое состояние без чувства вины.
- `studio-empty-v1.png` — создание → аналитика → публикация для Promo Studio.

Все растровые production-файлы имеют намеренный непрозрачный фон и не содержат
текста. Заголовки, суммы, статусы, прогресс и CTA должны оставаться живыми
React-компонентами.

### `icons/`

- `ui-sprite.svg` — 31 системная иконка: навигация, CRUD, импорт/экспорт,
  публикация, аналитика, статусы, чек, корзина, подарок и т. д.
- `category-sprite.svg` — 7 продуктовых категорий: базовая корзина, дом, гигиена,
  молочные продукты, снеки, детское питание, подгузники.
- `collection-sprite.svg` — 5 наград прогресса: starter, bronze, silver, gold,
  prestige.

Все символы имеют `viewBox="0 0 24 24"`, округлённый stroke и используют
`currentColor`.

Пример подключения:

```html
<svg width="24" height="24" aria-hidden="true">
  <use href="/assets/growth/icons/ui-sprite.svg#progress"></use>
</svg>
```

### `patterns/`

- `growth-contours.svg` — органические контуры прогресса.
- `dot-grid.svg` — спокойная точечная фактура.
- `reward-sparkles.svg` — акцент достижения.
- `studio-grid.svg` — фоновая сетка кабинета.

### `tokens/`

- `tokens.css` — CSS custom properties.
- `tokens.json` — те же значения для TypeScript/Figma-конвертации.

X5 Sans и X5 Sans UI указаны как приоритетные гарнитуры, но сами файлы шрифтов не
включены. До получения разрешённых файлов используется системный fallback.

### `source-renders/`

Четыре character-reference для дальнейшей генерации. Шахматная подложка в них
запечена в RGB, поэтому эти файлы не следует выводить в интерфейсе напрямую.

## Принципы использования

- production-персонажи используют матовую пластилиновую фактуру с видимыми
  следами лепки, неглубокими бороздками и слегка неровными краями;
- свет мягкий, тени короткие и рассеянные; глянцевый CGI и пластиковый toy-look
  не используются;
- зелёный остаётся основой, бежевый и мягкий сиреневый — вторичными акцентами;
- растры отвечают только за эмоцию и атмосферу;
- данные, тексты и интерактивность остаются кодом;
- системные действия используют SVG, а не emoji;
- оранжевый обозначает награду, зелёный — рост/успех;
- красный применяется только для риска и блокировки;
- пропущенная неделя не оформляется как ошибка;
- никакие файлы из этого пакета не являются логотипом X5.

## Generation

Растровые ассеты созданы встроенным `imagegen`. Clay-v2 prompt-набор фиксировал
handcrafted claymation, видимые следы ручной лепки, матовый материал, мягкие
короткие тени, идентичность персонажей, safe-zone под живой UI, отсутствие
встроенного текста, логотипов, товарных знаков и телефонных мокапов. Иконки,
паттерны и токены созданы детерминированно как SVG/JSON/CSS.
