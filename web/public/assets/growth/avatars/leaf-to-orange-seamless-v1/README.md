# X5 Рост — персонаж на поверхности приложения

Пять локальных вариантов для клиентского демо. Это не новая серия форм: каждая форма повторяет соответствующую стадию из `leaf-to-orange-v2`, но без декоративных контуров, звёзд и кремового фотосетапа. Изображения подготовлены на белом фоне, чтобы персонаж продолжал общую поверхность приложения и не выглядел вложенной карточкой.

Файлы: `stage-01-bud.png`, `stage-02-leaf.png`, `stage-03-fruit-set.png`, `stage-04-ripening.png`, `stage-05-orange.png`.

В клиентском демо персонаж получает лёгкое короткое приветственное движение по нажатию. Нажатие не меняет этап, накопленную экономию или другие данные. Лендинг также использует эту серию: главный персонаж, миниатюра следующего этапа, список форм и телефон. Исходные портретные ассеты из `leaf-to-orange-v2` сохранены для материалов.

Изображения намеренно RGB, не alpha-прозрачность: генератор вместо прозрачности возвращал шахматный паттерн. В демо слой отображается в режиме `multiply`: белая подложка растворяется в поверхности телефона, а края персонажа не выглядят вставленной карточкой.
