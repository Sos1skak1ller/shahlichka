# Экспертная разметка релевантности ранжирования акций (SC-002)

**Цель**: hit rate топ-предложений персонального ранжирования акций ≥ 70% на 30–50
held-out синтетических профилях. Разметку выполняет назначенный член команды.

## Как получить выборку

```bash
uv run python -m gaming_sim.eval_dump --kind promo --n 40 --seed 11 \
  --out specs/001-gaming-layer/eval/promo-samples.jsonl
```

Каждая строка: `{profile_id, segment, top_categories, ranked_promos:[{promo_id,
category, rank_score, margin_impact}]}` (топ-3).

## Чек-лист «попадание» для топ-1 акции (hit, если выполнено ЛЮБОЕ)

1. **Категория из истории** — `ranked_promos[0].category` входит в `top_categories`
   профиля.
2. **Смежная потребность** — категория топ-1 явно дополняет корзину профиля
   (напр. `diapers` при истории `baby_food`) — по суждению разметчика.

Дополнительно проверяем (не влияет на hit, но фиксируем как замечание):

- при равной релевантности выше стоит акция с большей `margin_impact` (FR-026);
- для профиля без истории порядок нейтральный, без ошибок (FR-027).

| | | | |

Итог: `# hit / # размеченных ≥ 0.70` → SC-002 выполнен.
