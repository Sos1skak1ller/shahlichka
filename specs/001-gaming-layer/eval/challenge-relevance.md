# Экспертная разметка релевантности челленджей (SC-001)

**Цель**: доля релевантных персональных челленджей ≥ 70% на 30–50 held-out
синтетических профилях. Разметку выполняет назначенный член команды по чек-листу
(открытый вопрос ТЗ 13 №3).

## Как получить выборку

```bash
uv run python -m gaming_sim.eval_dump --kind challenge --n 40 --seed 7 \
  --out specs/001-gaming-layer/eval/challenge-samples.jsonl
```

Каждая строка: `{profile_id, top_categories, avatar_level, archetype, challenge_text,
challenge_category, mechanic_type, generated_by}`.

## Чек-лист релевантности (ставим «да», если ВСЕ пункты выполнены)

1. **Категория из истории** — `challenge_category` входит в `top_categories` профиля
   (для `generated_by = fallback` — допускается категория по сегменту).
2. **Посильность** — целевое `n` не превышает 2× типичную недельную частоту покупок
   профиля в этой категории.
3. **Соответствие уровню** — механика не требует того, что недоступно на текущем
   `avatar_level` (напр. `cross_chain` не выдаётся ниже уровня 2).
4. **Формулировка понятна** — текст читается как одно конкретное действие с дедлайном.
5. **Без «ИИ»/«AI»** в тексте (FR-035).
